## Sobre o projeto

O SportiqFC (nome técnico do projeto: *sports-hub-unlocked*) é um portal de notícias esportivas com placares em tempo real, pensado para entregar informação rápida e atualizada aos torcedores.

## ✨ Funcionalidades

- 📰 Feed de notícias esportivas
- 🔴 Placares ao vivo
- 📱 Interface responsiva
